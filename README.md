# Three Worlds War

Juego de estrategia de bases (estilo Clash of Clans) con tres facciones: Resistencia, Voltempire y Nuwoks.
El juego está en `www/` (HTML5 + canvas).

Cada vez que se sube un cambio a `main`, GitHub compila la APK de Android automáticamente:
pestaña **Releases** → descarga `ThreeWorldsWar.apk` en el móvil e instálala.

Versión de prueba 0.1
